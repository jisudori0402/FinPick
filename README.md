# FinPick


### 1학기 관통 프로젝트 

#### 참여자 : 문지수, 박지훈




FinPick is a basic Django + Vue prototype for a social-first-year financial recommendation service.

## Run

1. cd backend
2. pip install -r requirements.txt
3. python manage.py migrate
4. python manage.py seed_finpick
5. python manage.py runserver

Then open http://127.0.0.1:8000/
